# Pop-up Delivery, Navigation & Analytics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop pop-ups being consumed before they are seen, let a pop-up open an event inside the app, accept bare-domain links, and show per-user interaction data in the admin.

**Architecture:** The Mobile API stops writing impressions during `/get-active-popups` for clients that opt in via `clientReportsViews: true`, and gains a `/record-popup-view` endpoint the app calls when the modal actually renders. Two additive optional columns on `popups` carry an event destination that the app routes through the existing notification navigation helper. The Statistics function's existing interaction pagination is extended to return a per-user list.

**Tech Stack:** Appwrite Functions (Node + TypeScript, `tablesdb`), React 19 + Vite + Tailwind 4 (admin), Expo SDK 54 + RN 0.81 (app).

**Spec:** [`docs/superpowers/specs/2026-09-11-popup-delivery-and-navigation-design.md`](../specs/2026-09-11-popup-delivery-and-navigation-design.md)

## Global Constraints

- **No test framework exists in either repo** (`CLAUDE.md`). TDD steps are replaced by build gates (`npm run build` / `npm run typecheck`) plus live staging exercise through the Appwrite CLI. Every task still ends with a verification step that must be *run*, not assumed.

- [ ] **Step 4: Add `recordPopupView`**

Directly after `getActivePopups`:

```ts
/**
 * Record that a pop-up was actually displayed. Idempotent per user/popup/day:
 * the existing row IS the dedup key, so a re-render cannot double-count.
 */
async function recordPopupView(
  databases: Databases,
  userId: string,
  popupId: string,
  log: (message: string) => void
): Promise<{ alreadyViewed: boolean }> {
  const now = new Date();
  const nowIso = now.toISOString();
  const dayKey = getPopupDayKey(now);

  let profile: PopupTargetingProfile;
  try {
    profile = (await databases.getDocument(
      DATABASE_ID,
      USER_PROFILES_TABLE_ID,
      userId
    )) as unknown as PopupTargetingProfile;
  } catch {
    throw { code: 404, message: 'User not found' };
  }

  let popup: PopupDocument;
  try {
    popup = (await databases.getDocument(
      DATABASE_ID,
      POPUPS_TABLE_ID,
      popupId
    )) as unknown as PopupDocument;
  } catch {
    throw { code: 404, message: 'Popup not found' };
  }

  // Never trust the client that this popup was theirs to see.
  if (!popupIsEligibleForUser(popup, profile, now)) {
    throw { code: 403, message: 'Popup is not eligible for this user' };
  }

  const existing = await databases.listDocuments(
    DATABASE_ID,
    POPUP_INTERACTIONS_TABLE_ID,
    [
      Query.equal('user', userId),
      Query.equal('popup', popupId),
      Query.equal('dayKey', dayKey),
      Query.limit(1),
    ]
  );

  if (existing.total > 0) {
    log(`Popup ${popupId} already recorded for ${userId} on ${dayKey}`);
    return { alreadyViewed: true };
  }

  await databases.createDocument(
    DATABASE_ID,
    POPUP_INTERACTIONS_TABLE_ID,
    ID.unique(),
    {
      popup: popupId,
      user: userId,
      dayKey,
      shownAt: nowIso,
      is21Plus: isUser21Plus(profile, now),
    }
  );
  await databases.updateDocument(DATABASE_ID, POPUPS_TABLE_ID, popupId, {
    views: (popup.views ?? 0) + 1,
  });

  return { alreadyViewed: false };
}
```

```ts
/**
 * Record that a pop-up was actually rendered. Fire-and-forget: the server
 * treats a repeat for the same user/popup/day as a no-op, so a retry is safe.
 */
export const recordPopupView = async (userId: string, popupId: string): Promise<void> => {
  const functionId = APPWRITE_EVENTS_FUNCTION_ID || '';

  if (!functionId || !userId || !popupId) {
    return;
  }

  try {
    const execution = await functions.createExecution({
      functionId,
      body: JSON.stringify({ userId, popupId }),
      method: ExecutionMethod.POST,
      xpath: '/record-popup-view',
      headers: {
        'Content-Type': 'application/json',
      },
      async: false,
    });

    if (execution.status === 'failed' && execution.responseBody) {
      console.warn('[popups.recordPopupView] Execution failed:', execution.responseBody);
    }
  } catch (error) {
    console.warn('[popups.recordPopupView] Error recording view:', error);
  }
};
```

// eslint-disable-next-line react-refresh/only-export-components -- shared helper, reused by EditPopupModal
export const normalizePopupLink = (raw: string): string => {
